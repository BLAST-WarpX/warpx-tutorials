# A Laser Wakefield Accelerator

The [episode](../../a-laser-wakefield-accelerator.Rmd) explains the physics,
installation requirements, run commands, and diagnostics.

Keep the input, driver, notebook, and plotting helper together in this folder.
Run from `laser-wakefield/`; diagnostics are written to `diags/diag1`.
The LLNL workshop's [startup script](../llnl-hpc-2026/startup.sh) creates
working copies from this folder, preserving any existing workshop files.
Figures remain here and are not copied.
