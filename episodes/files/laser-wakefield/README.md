# A Laser Wakefield Accelerator

The [episode](../../a-laser-wakefield-accelerator.Rmd) explains the physics,
installation requirements, run commands, and diagnostics.

Keep the input, driver, notebook, and plotting helper together in `lwfa_warpx/`.
Run from that folder; diagnostics are written to `diags/diag1`.
The LLNL workshop includes regular copies of the four files in `lwfa_warpx/`
under `../llnl-hpc-2026/htu/lwfa_warpx/`. Keep those copies synchronized when
updating this example; notebook paths and the input comment differ by location.
